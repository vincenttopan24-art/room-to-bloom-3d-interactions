# Batas dan keputusan integrasi

- Kode sumber Manus tidak ada di repo aset. Paket ini merupakan aplikasi demo lokal dan komponen integrasi; belum dipasang pada website terbit. Manus perlu menyambungkan state host, hotspot asli, dan efek merobek/meremas yang sudah ada.
- Audio bawaan adalah tujuh soundscape/musik sintetis asli, bukan rekaman lokasi. WAV 12 detik dapat diputar/loop dan dibuat ulang dengan generator. Gunakan `audioTracks`/AudioController untuk rekaman produksi milik host yang lisensinya sudah jelas.
- Tidak ada API AI berbayar atau kunci API. `aiRecommend` opsional; fallback kata kunci tetap berfungsi tanpa jaringan. Layanan AI host harus menangani autentikasi pada backend.
- Demo menyimpan progress pada localStorage, dengan validasi versi dan deadline timer. Sinkronisasi lintas perangkat dan backend merupakan tugas host melalui `onStateChange` dan pemetaan action. Jangan mengirim data privat ke layanan baru tanpa alur host yang berlaku.
- Jarum jam menggunakan titik putar tambahan; angka panjang memakai `maxHours + 1` posisi termasuk nol, dan jarum pendek memakai 60 posisi. Digital/numeric input adalah acuan durasi. Second Hand model disembunyikan pada salinan runtime agar tidak menyerupai kontrol ketiga.
- Halaman notebook merupakan mesh tambahan yang dideformasi di atas blok kertas asli. Sampul/ilustrasi/material model asli dipertahankan. Tulisan muncul per karakter dengan font cursive perangkat, bukan simulasi ujung pena. Sisi balik kertas kosong. Teks UI dibatasi 300 karakter; masukan host yang lebih panjang dapat mengecil atau terpotong.
- Fisika bin memakai gravitasi, deteksi lintasan melintasi mulut bin, radius interior, dan posisi tumpukan deterministik. Ini tidak menggunakan simulasi rigid-body seluruh karakter bin. Tumpukan sangat besar perlu penyesuaian kapasitas/ukuran kertas oleh host; area tampilan bin berukuran terbatas. Tidak ada kertas dekoratif acak.
- Penutupan saat kertas terbang mengembalikannya ke crumpled agar dapat dicoba lagi. Kertas binned tetap menjadi riwayat penyelesaian meskipun task kemudian dihapus atau dibuka ulang; ID task yang sama tidak menggandakan kertas.
- Gambar siang/senja berbeda tinggi satu piksel pada beberapa pasangan, dinormalisasi pada bidang aspek sama. Sembilan pasangan diperiksa secara visual. Hotspot demo hanya untuk objek yang tergambar; dock dapat membuka semua model. Hotspot host harus tetap memakai konfigurasi asli situs.
- Book stack dan island ikut disertakan sebagai aset asli; brief tidak menentukan animasi tambahan untuk keduanya.
- Browser harus mendukung WebGL. Kontrol HTML tetap tersedia bila WebGL tidak tersedia. Gerakan dapat dioperasikan melalui alternatif angka/tombol/keyboard, tetapi perangkat sentuh fisik dan pembaca layar host masih memerlukan QA integrasi.
